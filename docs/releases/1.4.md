# WristMemo 1.4

TestFlight build: 11

Released: 2026-08-08

## What's new

- The Watch capture surface now uses a restrained Swiss-spaced Helvetica
  treatment: a widely tracked **OFF**, a fine divider and compact instruction
  on charcoal, followed by a smaller widely tracked **RECORDING** on a deeper
  red field. The full-screen start and stop interaction is unchanged.

## What to test

1. On Watch, confirm the charcoal **OFF / TAP TO RECORD** screen is balanced,
   legible, and unclipped on the full display.
2. Start a memo and confirm the deep-red **RECORDING** label is centred and the
   start haptic still occurs only when the microphone is live.
3. Stop by tapping the screen and confirm the green receipt appears, then start
   another memo immediately while that receipt is visible.
